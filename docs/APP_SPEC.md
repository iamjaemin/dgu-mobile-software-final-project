# 식단 기록 앱 구현 범위 (P003–P006)

## 화면

- 시작 화면: 음식 입력. 하단에는 접근성 이름만 있는 아이콘 3개를 흰색·주황색 플로팅 캡슐에 배치한다.
- 식사 입력: 식사한 시간 → 음식과 반찬 → 사진 업로드 → 이번 식사 미리보기의 4단계. 진행률은 3dp의 얇은 막대로 표시한다. 이전/다음 이동 시 입력값을 유지하고, 음식 선택과 유효한 섭취량 입력 전에는 다음 단계를 막는다. 사진은 선택 사항이며 흰색 점선 영역의 카메라 + 아이콘을 눌러 선택한다.
- 날짜·시간: 하단 시트에 한국어 달력을 표시하고 그 아래 24시간제 시·분 스크롤 휠을 배치한다. 각 휠은 스크롤 종료 시 가운데 값에 스냅한다. `Locale.KOREA`와 한국어 리소스를 명시하며 UTC 자정 타임스탬프를 LocalDate로 변환한다. 휠이 움직이는 동안 적용을 막고, 적용 버튼을 눌러야 입력값을 바꾸며 닫으면 적용하지 않는다.
- 음식 검색: 하단 시트에 메뉴 분류별 카드와 음식 수를 표시한다. 메뉴 카드를 선택하면 해당 음식들이 나오며 검색어·카테고리 칩·식품 기원·g/mL 필터를 함께 적용할 수 있다. 여러 분류가 검색되면 분류 헤더로 구분한다. 음식 카드를 누르면 추가 후 시트 안의 스낵바로 완료를 알린다. 식품코드가 다르면 같은 이름도 유지한다. 항목 이름·섭취량을 수정하면 탄단지 및 kcal를 즉시 다시 계산한다.
- 식사 목록: 최신 날짜순 사진 카드의 2열 그리드. 날짜·시간·종류·음식 이름·열량과 날짜별 총 열량·기록한 끼니 수를 표시한다. 카드를 누르면 저장 당시 항목·섭취량·영양소·열량을 확인하며 기록 삭제도 지원한다.
- 식사 분석: 상단 총 열량 카드의 기간 드롭다운은 기본 1달, 추가로 7일·14일·하루를 제공한다. 하루 선택 시 날짜를 바꿀 수 있다. 아래 2열 그리드에 끼니 수·하루 평균·시간대별 카드, 전체 너비의 탄단지 도넛·막대 그래프와 날짜별 열량 그래프를 배치한다. 모든 카드와 그래프는 같은 선택 기간을 사용한다.
- 시간대: 식사 종류와 무관하게 실제 기록 시각을 기준으로 새벽(00:00–05:59), 오전(06:00–11:59), 오후(12:00–17:59), 저녁(18:00–23:59)의 탄단지·열량·횟수를 집계한다. 최근 한 달은 `오늘.minusMonths(1).plusDays(1)`부터 오늘까지이며 미래 기록은 오늘 기준 기간 분석에서 제외한다.
- 출처: 앱 안에 식품의약품안전처 K-FIND와 공공데이터포털 원본 링크, 선별 수·기준 및 단위 설명을 표시한다.

## 표현과 계산

Pretendard Regular·Medium·Bold를 오프라인 폰트로 동봉한다. Primary는 `#ff6f0f`, 화면 배경은 `#fafafa`, 카드는 `#ffffff`, 입력 필드는 `#f8f8f8`이다. 기존 갈색·살구색은 제거하고 본문·보조 정보·구분선은 중립 회색을 사용한다. 카드와 플로팅 탐색에는 옅은 그림자를 적용한다. 입력 필드는 테두리·밑줄·상단 라벨 없이 placeholder와 접근성 이름을 제공한다. 버튼과 칩은 둥근 모서리다. 다크 모드와 동적 색상은 적용하지 않는다. 사진은 원래 색을 유지한다. 탄단지 균형은 각 영양소 g 및 4/4/9 환산 에너지 비율로 표시하고 건강 판정이나 개인별 권장량으로 해석하지 않는다. 열량 합계에는 DB 원본 kcal를 사용한다. 폰트 출처와 라이선스는 [THIRD_PARTY.md](THIRD_PARTY.md)에 기록한다.

음식은 g, 부피 기준 음료는 mL로 입력한다. 밀도 없이 mL를 g으로 바꾸지 않는다. 음식·반찬은 DB 항목과 연결하고 표시 이름을 수정할 수 있다. 분석은 한 번 저장한 식사를 한 끼로 세며 같은 종류를 여러 번 기록하면 각각 센다.

## 저장과 브랜치

음식 JSON은 Android assets로 패키징한다. 식사 기록은 앱 내부 저장소의 AtomicFile JSON에 저장하고 매번 저장 당시 영양소를 보관한다. 쓰기가 실패하면 기존 파일을 보존하고 사용자에게 오류를 표시한다. 사진은 선택 직후 앱 전용 임시 파일로 축소 복사하고 저장 성공 후 기록이 참조한다. 기록 삭제·교체 시 더 이상 참조하지 않는 사진을 정리한다. 외부 저장소 전체 권한 없이 시스템 사진 선택기를 사용한다.

브랜치는 요청대로 저장소·계산·UI 작업을 분리해 커밋한다. 초기 공통 코드는 fast-forward로 반영했고, 이후 시간대별 계산은 계산 브랜치에서 커밋한 뒤 필요한 변경을 UI 브랜치에 병합했다. 최종 통합 앱은 `feature/ui-compose`에서 검증하며 main에는 자동 병합하지 않는다.

## 검증

데이터 변환 기존 테스트, 순수 Kotlin 단위 테스트(양·단위·날짜 경계·0 데이터·종류별 합계), 저장 직렬화 및 재실행 복구 테스트, Compose 입력·목록·상세·출처 테스트와 APK 빌드·lint를 수행한다. 실제 기기/에뮬레이터에서 가능한 범위는 결과와 함께 기록한다.

구현 시 [Compose 설정](https://developer.android.com/develop/ui/compose/setup), [Compose BOM](https://developer.android.com/develop/ui/compose/bom), [내장 Kotlin](https://developer.android.com/build/migrate-to-built-in-kotlin), [시스템 사진 선택기](https://developer.android.com/training/data-storage/shared/photo-picker)의 공식 문서를 확인했다.

### P004 화면 개편 검증

- Kotlin 단위 테스트 8개(계산·시간대 경계 7개, 기본 1개), Android 에뮬레이터 테스트 8개(저장소·사진 4개, UI 3개, 기본 1개)를 통과했다.
- 영문 설정 기기에서 한국어 월·요일 표시를 확인하고, 달력 아래 시·분 선택을 배치했다. 시트에 진입하자마자 키보드가 뜨지 않으며 선택값은 적용 버튼으로 확정한다.
- 음식 입력을 시작 화면으로 확인하고 네 단계 이동, 유효한 음식 입력 전 진행 차단, 카테고리 필터, 결과 없음, 다중 선택 시트, 영양소 미리보기, 저장·상세·삭제를 검증했다.
- 분석은 기본 1달이며 7일 선택 시 총 열량이 300kcal에서 200kcal로 갱신되는 고정 자료 테스트를 통과했다. 종류가 모두 중식인 기록도 실제 08시/20시를 기준으로 오전/저녁 카드에 각각 표시했다.
- 시각 경계 00:00/05:59/06:00/11:59/12:00/17:59/18:00/23:59를 단위 테스트로 확인했다. 각 시간대는 시작 시각 포함·다음 시작 시각 미포함이다.
- 한국어 리소스를 강제로 선택하는 달력을 위해 App Bundle 언어 분할을 끄고, Android lint 오류 없이 빌드했다. 기존 의존성 새 버전 안내는 유지했다.

달력 상태와 UTC 타임스탬프 해석은 [DatePickerState 공식 API](https://developer.android.com/reference/kotlin/androidx/compose/material3/DatePickerState)를 확인했다. 그래프에 접근성 설명과 수치 라벨을 제공한다. 막대 그래프는 카드 안의 상대량 비교이며 권장량 대비 달성률이 아니다.

### P005 테마 및 시간 휠 검증

- APK 빌드 성공, 단위 테스트 8개 및 Android 17 에뮬레이터 테스트 9개 통과, lint 오류 0개.
- 라벨 없는 입력 필드를 접근성 이름으로 검색·편집하고 식사를 저장하는 흐름을 검증했다. 시·분 휠에서 선택한 18:05가 입력값으로 적용되는 것을 확인했다.
- 휠의 00:00·23:59 경계와 실제 스와이프 후 선택 항목이 중앙에 맞춰지는 동작을 검사했다. 화면 회전 이후에도 저장한 식사 상세를 복원하는 기존 검사도 통과했다.
- 실행 화면 캡처로 Pretendard 한글, 새 색상, 흰색 카드의 옅은 그림자, 얇은 진행 막대, 둥근 칩과 시간 휠을 검토했다.
- 사진 업로드는 흰색 점선 영역과 카메라 + 아이콘으로 변경했으며, 영역 전체를 버튼으로 사용할 수 있다. 이미지가 있으면 영역 안에 미리 보고 같은 영역을 눌러 교체한다.
- Pretendard v1.3.9 원본 OTF 3개와 SIL OFL 1.1 라이선스를 함께 패키징했다. 폰트의 출처·해시는 [THIRD_PARTY.md](THIRD_PARTY.md)를 참고한다.

### P006 검색 및 날짜별 열량 그래프

- 기본 검색 시트는 메뉴 분류 카드 → 음식 카드 순으로 탐색한다. 음식 추가 완료 알림은 시트 내부에 표시하고 연속 추가 시 최신 알림으로 교체한다.
- 날짜별 열량은 개별 날짜 행을 제거하고, 날짜를 가로축·kcal를 세로축으로 하는 하나의 막대그래프로 표시한다. 긴 기간에는 날짜 눈금을 간추리며, 기록이 없는 날도 0kcal로 포함한다. 전체 기간 값은 접근성 설명으로 제공한다.
- 빌드·단위 테스트 8개·에뮬레이터 테스트 9개 통과, lint 오류 0개. 메뉴 카드 탐색, 추가 완료 스낵바 표시, 저장·삭제를 검증했다. 그래프가 1달에서 7일로 변경될 때 기간 밖 기록은 제외하고 기간 안 기록은 유지하는 것을 확인했다.
